# Москва — МойСклад

## Назначение

Каталог из МоегоСклада пересобирается в существующих товарных листах Google Таблицы. После подключения создаётся триггер примерно раз в 15 минут.

## Установка в Apps Script

Скопировать в связанный с таблицей Apps Script **только** два файла из этой папки:

1. `MoySkladCatalog.gs` — файл типа **Script**.
2. `MoySkladCatalogSidebar.html` — файл типа **HTML**.

После обновления таблицы открыть меню **«Каталог из МоегоСклада»**, ввести «Магазин | Город» и API-токен, затем нажать **«Подключить МойСклад»**.

## Статус текущей версии

Текущий коммит намеренно сохраняет последнюю ранее рабочую конфигурацию. Отдельная маршрутизация аксессуаров на лист `аксессуары` **ещё не внедрена**: аксессуары, кроме наушников, пока могут попадать в `телефоны`.

## Следующая задача для Москвы — не применять в этом коммите

- В листе `телефоны` должны оставаться только реальные телефоны. Apple и Android направляются в соответствующие блоки.
- Чехлы, стекла, кабели, зарядки, адаптеры, ремешки, держатели, powerbank, игровые аксессуары и похожие товары направлять на лист `аксессуары`.
- AirPods, EarPods и остальные наушники направлять на лист `наушники`.
- MacBook, iMac, iPad, часы, приставки и Dyson направлять на одноимённые товарные листы.
- Парсер обязан различать Apple-устройства и аксессуары: слово «iPhone» в описании чехла не делает этот товар телефоном.
- API-токен никогда не добавлять в репозиторий или ячейки.

Перед этой доработкой обязательно обновить тесты, затем один раз выполнить «Пересобрать каталог сейчас» в клиентской таблице.

## Проверка

```bash
cd 'Москва/МойСклад'
node test-moysklad-catalog.mjs
```

В Apps Script проверять один триггер `syncMoySkladCatalog` и успешные запуски в разделе «Выполнения».
