# Ульяновск: вариант с НОБЕЛЬ.РФ

Это самостоятельный пакет для ручной загрузки в связанный Apps Script.
Он не изменяет каталог поставщика первого этапа и не использует старую
Avito-таблицу.

## Файлы для загрузки

Загружать вместе:

1. `TelegramCatalog.gs`
2. `PriceFlowAvitoMatcher.gs`
3. `PriceFlowTemplateMatcher.gs`
4. `PriceFlowNobelCatalog.gs`
5. `TelegramCatalogSidebar.html`

`current` — резервный неизменный вариант без НОБЕЛЬ.РФ. Для отката нужно
загрузить его одноимённые файлы вместо этого пакета.

## Гарантии этого варианта

- Сначала выбирается безопасный кандидат из готового каталога Ульяновска.
- НОБЕЛЬ.РФ используется только при отсутствии такого кандидата и только по
  положительной цене `BASE`.
- Все шапки и все семь разделов НОБЕЛЬ.РФ должны пройти разбор до первой
  записи в шаблон; любая ошибка отменяет весь запуск.
- Резервная цена получает ярко-жёлтый фон. В уже разрешённых соседних
  диагностических колонках записывается `Цена из сайта: НОБЕЛЬ.РФ`.
- Данные НОБЕЛЬ.РФ не сохраняются в готовом каталоге поставщика.
