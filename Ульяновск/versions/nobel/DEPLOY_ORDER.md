# Порядок безопасного переключения

1. Не удалять папку `../current` и не менять её файлы.
2. В Apps Script создать отдельную версию проекта или сохранить текущую
   версию перед загрузкой.
3. Загрузить пять файлов из `README.md` как единый набор.
4. Запустить только `runPriceTemplateSyncNow` и проверить отчёт: в нём должны
   быть `primaryMatched`, `nobelMatched` и данные загрузки НОБЕЛЬ.РФ.
5. При проблеме вернуть пять одноимённых файлов из `../current`.

Нельзя смешивать `TelegramCatalog.gs` из одного варианта с matcher-файлами
из другого: пакет переключается целиком.
