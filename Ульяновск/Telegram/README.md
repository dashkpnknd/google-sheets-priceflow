# Ульяновск — Telegram

## Назначение

Каталог из публичного Telegram-канала `@opt_uniseil` пересобирается в существующих листах Google Таблицы. После подключения создаётся триггер примерно раз в 15 минут.

## Установка в Apps Script

Скопировать в связанный с таблицей Apps Script четыре файла:

1. `TelegramCatalog.gs` — файл типа **Script**.
2. `../../PriceFlowAvitoMatcher.gs` — файл типа **Script** с общими правилами безопасного совпадения (Avito из него больше не вызывается).
3. `../../PriceFlowTemplateMatcher.gs` — файл типа **Script** (отдельный файл с именем `PriceFlowTemplateMatcher`).
4. `TelegramCatalogSidebar.html` — файл типа **HTML**.

Затем обновить Google Таблицу, открыть меню **«Каталог поставщика»**, указать магазин/город и `@opt_uniseil`, нажать **«Подключить Telegram-канал»**.

После каждой успешной пересборки готового каталога цены синхронизируются только
в согласованный шаблон цен. Синхронизация читает только готовые листы и
изменяет только существующие колонки `Price`; Avito не открывается и не меняется.

## Правила Ульяновска

- Сохранять страну в отдельной колонке вместе с флагом.
- Выбирать самую дешёвую подходящую позицию поставщика для конкретного набора характеристик; цвет является частью этого набора.
- Применять наценку строго из клиентского файла правил.
- Если включена опция в панели, создавать дополнительную строку `2 SIM` с ценой варианта `SIM + eSIM`.
- Не зависеть от выпадающих списков: записывать текст, поскольку ассортимент поставщика может содержать новые значения.
- Телефоны и Android-блоки должны быть заполнены из одного каталога, по правилам маршрутизации в скрипте.

## Проверка

```bash
cd 'Ульяновск/Telegram'
node test-telegram-catalog.mjs
```

В Apps Script проверять один триггер `syncTelegramCatalog` и успешные запуски в разделе «Выполнения».
