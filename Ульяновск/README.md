# Ульяновск

В этой папке хранится клиентская реализация для Ульяновска.

- Интеграция: Telegram.
- Поставщик: публичный канал `@opt_uniseil`.
- Точка входа: [`Telegram/README.md`](Telegram/README.md).

Не использовать настройки этой папки для Москвы: здесь действуют индивидуальные правила наценки, страны и конфигурации `2 SIM`.
