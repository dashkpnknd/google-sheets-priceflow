# Эплтрейд | Белая Калитва

Проект собирает только опубликованные цены двух поставщиков Telegram:

- закрытый канал по приглашению `+7uEm3vcRuBRiNWZi` — только если уже доступен
  авторизованному аккаунту; сервис никогда сам не вступает в канал;
- публичный канал `@ilublino`.

Для одинакового нормализованного SKU сохраняется минимальная цена поставщика с
указанием источника и времени сообщения. Результат предназначен для трёх
получателей: Telegram-бота `@AppleTrade_price_bot`, товаров VK и раздела
«Товары» в Яндекс Картах.

## Границы автоматизации

Сбор и расчёт минимальных цен можно автоматизировать без дополнительных
доступов. Публикация в каждом получателе требует отдельной явной настройки:

- Telegram-бот: формат команд/кнопок и подтверждение, что аккаунт уже имеет
  права редактирования цен;
- VK: `group_id`, access token с правом редактировать товары и стабильная
  связка `SKU → item_id`;
- Яндекс Карты: доступ к Яндекс Бизнесу и способ загрузки товаров (API или
  поддерживаемый фид), а также связка `SKU → товар`.

Пока этих ключей/связок нет, сервис отдаёт проверяемый JSON-снимок и CSV с
минимальными ценами, но не публикует и не меняет внешние площадки.

## Безопасность

- Telegram-сессия, API credentials, токены, chat id и секреты endpoint не
  хранятся в Git, Google Sheets или handoff.
- Закрытый канал не импортируется автоматически: проверяется только текущий
  доступ. Если аккаунт не состоит в нём, требуется, чтобы пользователь сам
  добавил аккаунт через приглашение.
- Товары никогда не сопоставляются по похожему названию при конфликтующих
  модели, памяти, SIM, цвете или типе устройства.
