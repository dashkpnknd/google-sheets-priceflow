# Google Sheets PriceFlow

Репозиторий с двумя отдельными Google Apps Script-реализациями для клиентских Google Таблиц. Это не единый скрипт, который нужно устанавливать целиком: для каждого клиента копируется только его папка.

| Клиент | Интеграция | Папка |
| --- | --- | --- |
| Ульяновск | Публичный Telegram-канал `@opt_uniseil` | `Ульяновск/Telegram/` |
| Москва | API МоегоСклада | `Москва/МойСклад/` |

## Что открывать в первую очередь

Подробная передача, индивидуальные правила и отложенные задачи находятся в [HANDOFF.md](HANDOFF.md). Перед изменениями конкретного клиента прочитайте также README внутри его папки.

## Установка в Google Apps Script

Для выбранного клиента в связанный с его Google Таблицей Apps Script добавляются только два канонических файла:

1. `*.gs` — тип файла **Script**;
2. `*Sidebar.html` — тип файла **HTML**.

После сохранения обновите Google Таблицу, откройте меню соответствующего продукта и выполните подключение через боковую панель. Токены и другие секреты не входят в этот репозиторий.

## Проверка

Тесты запускаются локально из папки нужного продукта:

```bash
cd 'Ульяновск/Telegram'
node test-telegram-catalog.mjs

cd '../../Москва/МойСклад'
node test-moysklad-catalog.mjs
```

Исторические файлы в `outputs/` намеренно не являются частью этой поставки: актуальный код, тесты и документация находятся только в клиентских папках выше.
