# Электросталь — Telegram

## Назначение

Этап 1 пересобирает каталог из текущих ценовых постов публичного Telegram-канала. Этап 2 читает только готовый каталог и обновляет только `Price` в существующих строках таблицы цен. Модели, варианты, строки, листы и оформление таблицы цен этап 2 не меняет. Расписание каталога: 00:00, 05:00, 10:00, 15:00 и 20:00 по часовому поясу проекта Apps Script.

## Установка в Apps Script

Скопировать в связанный с готовым каталогом Apps Script четыре файла:

1. `TelegramCatalog.gs` — файл типа **Script**.
2. `PriceFlowAvitoMatcher.gs` — файл типа **Script** (отдельный файл `PriceFlowAvitoMatcher`).
3. `PriceFlowTemplateMatcher.gs` — файл типа **Script** (отдельный файл `PriceFlowTemplateMatcher`).
4. `TelegramCatalogSidebar.html` — файл типа **HTML**.

Затем обновить Google Таблицу, открыть меню **«Каталог поставщика»**, указать магазин/город `Электросталь | Электросталь` и `@astoredirectprice`, нажать **«Подключить Telegram-канал»**.

## Источник и правила Электростали

Указанный поставщик `@astoredirect` — витринный канал; его кнопка «Открыть актуальный прайс» ведёт на `@astoredirectprice`. В панели используется именно этот публичный прайс-канал, потому что в нём товары и цены опубликованы текстом.

- Сохранять страну в отдельной колонке вместе с флагом.
- Для Apple: 5–15 тыс. +3 000; 16–35 +4 000; 36–69 +5 000; 70–89 +6 000; 90–110 +7 500; 111–150 +9 000; 151–225 +13 000 ₽.
- Для Android: 5–15 тыс. +3 000; 16–35 +5 000; 36–69 +7 000; 70–89 +8 000; 90–110 +8 500; 111–150 +10 000; 151–225 +15 000 ₽.
- После наценки цена всегда округляется вверх до ближайших 500 ₽ и записывается числом без разделителей тысяч.
- Текущая реализация применяет вторую шкалу ко всем не-Apple позициям. В этой работе правила наценки не менялись.
- Пометки поставщика `(Active)` / `(Уценка)` сохраняются в начале названия товара, включая позиции, где такая пометка стоит перед `iPhone`.
- Не зависеть от выпадающих списков: записывать текст, поскольку ассортимент поставщика может содержать новые значения.
- Телефоны и Android-блоки должны быть заполнены из одного каталога, по правилам маршрутизации в скрипте.
- Если раздел актуального прайса разбит на сообщения «часть N/M», каталог читает все объявленные части. Если хотя бы одна часть не найдена или помечена иначе, пересборка останавливается до записи: цены Avito не будут ошибочно очищены по неполному прайсу.
- Текущая навигация поставщика содержит ссылки на начало разделов. Сборщик читает все ссылки и соседние сообщения-продолжения; при недоступной ссылке или неполном результате каталог не перезаписывается. Старые строки каталога не подмешиваются к успешно прочитанному полному прайсу.
- Android-модель хранится отдельно от памяти, RAM, SIM, цвета и радио-модификации. Повторное чтение готового каталога сохраняет разложенные поля, чтобы название модели не разрасталось при каждом запуске.
- Во втором этапе `Vendor` используется для моделей Xiaomi и HONOR, у которых в шаблоне бренд вынесен в отдельную колонку. Сопоставление остаётся точным по модели, памяти, известному цвету и RAM; отсутствие RAM в прайсе поставщика не заполняется догадкой.
- Для нескольких конкретных Pixel 11 без RAM в названии поставщика применяется подтверждённая конфигурация из отчёта по прайсу 06.11.2026. Остальные неизвестные RAM остаются пустыми. Цвета `Whitesilver`, `Silver Shadow`, `Titanium Silverblue`, `Graphite`, `Canyon`, `Olive`, `Fog` и отдельные оттенки HONOR 400 сопоставляются с существующими значениями шаблона без изменения его строк.
- Цены берутся из актуального сообщения поставщика при каждом запуске. Контрольная цена из отчёта за 06.11.2026 может устареть после редактирования поставщиком того же сообщения.
