# Яблочный Спас | Орск — RM Group

Apps Script получает прайс-лист методом `pricelist.get` из официального RM Group Client API и пересобирает стандартные товарные листы раз в 15 минут.

## Что нужно для запуска

1. Создать/открыть таблицу со стандартными листами: `телефоны`, `аксессуары`, `макбуки`, `аймаки`, `айпады`, `часы`, `наушники`, `пс`, `дайсон`.
2. Вставить `RMGroupCatalog.gs` и `RMGroupCatalogSidebar.html` в Apps Script.
3. Открыть меню **Каталог RM Group**, в панели вставить выданный командой RM Group API-токен и нажать первую синхронизацию.

Токен сохраняется только в Script Properties. Он не попадает в код, Git или handoff. API по документации доступен с 11:00 до 18:00 МСК; вне этого периода API отвечает `425`.

Пока владелец проекта не дал ценовые правила, цены из API пишутся без наценки.
